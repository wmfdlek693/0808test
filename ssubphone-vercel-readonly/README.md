# 썹폰 · 김주은 — 읽기 전용 배포본

원본 `썹폰(1).zip`에서 제공된 **홈 화면 HTML, CSS, 앱 아이콘**을 활용하고, `profiles_20261020 2.json`에서 제공된 **프로필 데이터**를 그대로 읽는 정적 웹사이트입니다.

## 2026-10-20 X 화면 수정 사항

- 사용자 제공 `IMG_2464.png` 원본 편집 화면을 기준으로 X 상단 로고, 추천/팔로잉 탭, 타임라인 작성자 줄과 상대시간, 4개 하단 메뉴를 재구성했습니다.
- 내 프로필은 저장된 아이콘이 없어 원본 캡처를 참고해 강아지 이모지로 표시합니다.
- JSON에 담긴 게시물을 시간 및 답글 관계로 묶어 표시하고, 스레드의 점 표시를 누르면 중간 답글을 열람할 수 있습니다.
- 피드 시간은 접속한 기기 시각을 기준으로 계산됩니다. 배포 후 시간이 지나면 `43분 전`이 계속 고정되지 않습니다.
- 답글·좋아요 등의 숫자는 저장된 데이터만 표시하며, 저장값이 0인 답글 수는 실제 데이터 안에 연결된 직접 답글 개수로 보완합니다.
- 배포 링크는 아직 생성되지 않았습니다.

## 구현 범위

- 읽기: X(트위터) 타임라인/게시물/답글 관계/프로필/사진, iOS 문자 대화, 연락처, 인스타그램 및 카카오톡에 저장된 데이터(현재 빈 목록)
- 클릭: 앱 아이콘, 탭, 게시물, 작성자 프로필, 연락처, 대화방, 사진 전체보기, 뒤로 가기, 홈으로 돌아가기
- 없음: 데이터 작성/편집/삭제, 로그인, 실제 전화/문자 전송, 계정 팔로우/좋아요 등 쓰기 동작
- 기타 앱은 JSON 내에 보존된 콘텐츠가 없으면 빈 화면 안내만 표시
- 원본 `.zip`에는 기능을 담당하는 핵심 `app.js`가 들어 있지 않아 **완전한 복원은 불가**. 원본 홈 디자인과 CSS는 활용했지만 앱 내 동작은 새로 구현한 열람 전용 버전입니다.

## Vercel 배포

### 가장 간단한 방법 — Vercel Drop

1. ZIP 파일을 압축 해제합니다.
2. [Vercel Drop](https://vercel.com/drop)에 접속합니다.
3. 압축 해제한 `ssubphone-vercel-readonly` **폴더 전체**를 화면으로 끌어다 놓습니다.
4. 프로젝트 이름을 정하고 **Deploy**를 누르면 공개 URL이 만들어집니다.

### GitHub를 이용하는 방법(자동 갱신용)

1. 압축을 풀어 `index.html`, `readonly.js`, `readonly.css`, `profile-data.js`, `profile-data.json`, `assets/`가 동일한 프로젝트 루트에 있도록 둡니다.
2. GitHub의 새 저장소에 압축 해제된 파일을 올립니다.
3. Vercel → Add New Project → GitHub 저장소 Import → Framework Preset `Other` → Deploy. 별도의 빌드 명령은 없습니다.
4. 로컬 시험 실행: 프로젝트 폴더에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000`으로 접근하세요. `profile-data.js`를 함께 두면 `index.html`을 더블클릭해서도 열람할 수 있습니다.

## 공개 범위 / 개인정보

사이트는 `profile-data.js`를 브라우저에서 다운로드하여 렌더링합니다(`profile-data.json`에도 같은 데이터가 있습니다). 따라서 Vercel **공개 배포 시 JSON 전체가 인터넷에 노출**됩니다(실제 번호, 문자 내용, 사용자 제작 콘텐츠 및 이미지). `noindex`는 검색 인덱싱 요청일 뿐 접근 제어가 아닙니다. 공개하기 전에 JSON 데이터와 이미지를 확인하고 필요한 정보를 제거하십시오. 개인적으로 사용하려면 Vercel 접근 제어를 따로 구성해야 합니다.

## 지원 / 주의

외부 서비스와 실시간 연결하지 않습니다. 데이터 읽기 전용이며 클릭은 이 배포본 안에서만 탐색합니다. 배경화면은 기존 자료에 있는 외부 URL을 사용하며, 해당 서버가 응답하지 않으면 CSS 기본 그라데이션을 표시합니다.
